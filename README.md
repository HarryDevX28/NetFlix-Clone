# Netflix Clone

A Netflix landing page clone made using HTML and CSS.

This project was built as a practice project to improve my HTML and CSS
skills, especially responsive layouts, Flexbox, positioning, media
queries, and page structure.

## Features

-   Netflix-inspired landing page
-   Responsive layout for different screen sizes
-   Hero section with email input and buttons
-   TV and mobile sections
-   Embedded videos
-   FAQ section UI
-   Footer with navigation links
-   Custom images and assets

## Technologies Used

-   HTML5
-   CSS3
-   Flexbox
-   Media Queries
-   Google Fonts

## How to Run

1.  Download or clone this repository.
2.  Open the project folder.
3.  Open `index.html` in a browser.

No additional setup is required.

## Note

This is a frontend practice project inspired by the Netflix website. It
is not an official Netflix website and does not include real Netflix
services, accounts, payments, or streaming functionality.

The FAQ section and some footer links are currently only part of the UI
and are not fully functional.
